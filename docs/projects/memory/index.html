06Book Design

MEMORY ///

The book explores the changing nature of memories and the way they fade over time. Through visual and typographic language, the project reflects how memories gradually wear down, disappear, or remain only as fragmented moments. The design mirrors the process of remembering, where some details stay sharp while others blur and slowly dissolve.
