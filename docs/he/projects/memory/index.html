MEMORY ///

הספר חוקר את טבעם המשתנה של זיכרונות ואת האופן שבו הם דוהים עם הזמן. באמצעות שפה חזותית וטיפוגרפית, הפרויקט משקף כיצד זיכרונות נשחקים בהדרגה, נעלמים או נותרים רק כרגעים מקוטעים. העיצוב מהדהד את תהליך ההיזכרות: חלק מהפרטים נשארים חדים, בעוד אחרים מיטשטשים ומתמוססים לאט.
